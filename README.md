# Final Project – IT 412

This project processes customer data from a raw text file and loads it into:

- JSON format (customer_phone.json)
- CSV format (customer_location.csv)
- Two SQLite database tables

## Features
- Import raw data file
- Clean and validate data
- Remove duplicates
- Export JSON and CSV
- Add, edit, delete records
- Show table data
- Full menu-driven program
- Unit tests using unittest and pytest
